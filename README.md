# Nexora - AI-Powered E-commerce Website

Nexora ek modern aur AI-driven e-commerce website interface hai jise HTML, CSS, aur JavaScript ki madad se design kiya gaya hai. Isme smart features aur interactive shopping experience ka integration shamil hai.

## 🚀 Features
- **Smart Product Recommendations & AI Help:** Users ki shopping aur browsing history ke mutabiq smart picks aur AI assistance ka option.
- **Advanced Filtering:** Categories, Price range, aur Ratings ke hisaab se products ko filter karne ki sahuliyat.
- **Trending & Bundles Section:** Trending items aur special bundle discounts ka display.
- **Interactive Cart & Saved Items:** Items ko cart mein add karna, checkout karna, aur wishlist mein save karne ka feature.
- **FAQ & Customer Reviews:** Real customer feedback aur common questions ka section.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Styling & UI:** Responsive layout with modern CSS design
